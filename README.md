# Computer Bedrock Addon for Minecraft Bedrock Edition

A custom addon for Minecraft Bedrock that adds computer-themed blocks and functionality.

## Project Structure

```
.
├── behavior_pack/              # Game logic and functionality
│   ├── manifest.json          # Behavior pack metadata
│   ├── functions/             # Command functions
│   ├── entities/              # Custom entities
│   └── blocks/                # Custom block definitions
├── resource_pack/             # Visual assets
│   ├── manifest.json          # Resource pack metadata
│   ├── models/                # 3D block and item models
│   └── textures/              # Block and item textures
└── README.md                  # This file
```

## Installation

1. Download or clone this repository
2. Compress both `behavior_pack` and `resource_pack` folders as `.mcaddon` files
3. Import into Minecraft Bedrock Edition
4. Enable the addon in world settings
